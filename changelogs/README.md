# Compression Changelogs

This folder contains all changelogs for the modpack since 2.0.0.r  
Changelogs are updated as things get added, so generally, a changelog for an unreleased version will reflect what is currently done for it.  
Changelogs for upcoming versions only contain features or fixes that are completed and would be present should that version be released in this instant.

Formatting:  
**2.[n].[m]** - Where **n** is the update within the tier being worked on and **m** is a minor update or hotfix  
**.b** - Beta release  
**.r** - Completed release version  
**.r.[n]** - Hotfix to a release version where **n** increments.
