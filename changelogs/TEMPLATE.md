# Compression Changelogs
Formatting:  
**2.[n].[m]** - Where **n** is the update within the tier being worked on and **m** is a minor update or hotfix  
**.b** - Beta release  
**.r** - Completed release version  
**.r.[n]** - Hotfix to a release version where **n** increments.

# 2.n.m.r
- ### New Features
    - Lists major additions, like new mechanics.

- ### New Mods
    - Lists newly added mods

- ### Updated Mods
    - Lists updated mods
    - Format: Mod Name (Old.Version -> New.Version, Optional: Reason for update)

- ### New Items
    - Lists newly registered items, usually from Nyagi's Bits & Bytes

- ### New Recipes
    - Lists brand new recipes

- ### Changed Recipes
    - Lists changes to existing recipes
    - Fixing mistakes in recipes should go under Fixes

- ### Removed Recipes
    - Lists recipes that have been removed.
    - Should specify what type of recipe it was.

- ### Ponders
    - Lists newly added ponders or changes to existing ponders

- ### Quests
    - Lists changes to the questbook

- ### Renamed Items
    - Lists item that have been renamed for the sake of flavour.
    - Format: Old Name -> New Name

- ### Changes
    - Lists changes that don't fit neatly into other categories.
    - Could be config changes, or broader changes to a mechanic, it's non-specific on purpose.

- ### Fixes
    - Lists any bugfix done on the pack's side.
    - Includes fixing any broken recipe or tag.
