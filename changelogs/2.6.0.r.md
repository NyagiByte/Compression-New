# Compression Changelogs
Formatting:  
**2.[n].[m]** - Where **n** is the update within the tier being worked on and **m** is a minor update or hotfix  
**.b** - Beta release  
**.r** - Completed release version  
**.r.[n]** - Hotfix to a release version where **n** increments.

# 2.6.0.r

- ### Features
	- A new Create filter type is now available @ExXec
		- The ingredient filter only allows processing if one or more specific ingredients are present in the basin.
		- Particularly useful for recipes like scaled andesite/livisite alloy, which fully contain the ingredients of the previous recipe and have the same type of output.
		- Can also filter for specific fluids, either by using a fluid container, or by specifying the fluid directly in the filter (Can be toggled between the teo)
		- Can be toggled to allow the recipe if any ingredient matches, or only if ALL ingredients match.
		- Can accept list filter or attribute filters in its slots, for more elaborate filtering behaviour.
	- Automating pufferfish was de-magicboxified. @Barza
		- Thermal's Aquatic Entangler is no longer craftable
			- It can be broken to recover all materials used to make it...almost
		- Cocoons of Caprice have been significantly buffed
			- They now hatch in 5 seconds instead of two whole minutes.
			- They no longer spawn cod, salmon or tropical fish. Frogs are now a rare spawn.
			- What this does, is let pufferfish, squids and crabs be the only contenders for a common spawn, making them spawn more than twice as often.
			- This makes the cocoon a viable source of pufferfish. The ink is also very much nothing to scoff at.
			- Land spawns remain unchanged, at least for now.
	- A significant amount of create fixes were backported with Create: Repair. Notable fixes include
		- Mechanical assemblers dropping items upon loading an area back in.
		- Factory gauges don't see the available stock and send requests all at once upon loading an area back in.
		- Some block entities crash clients on contraptions (Root cause of the Packages crash)
		- [And many more](https://github.com/VoidLeech/Repair/blob/mc1.20.1/forge/dev/REPAIRED.md)
	- Reworked throwing pebbles to be a somewhat usable early weapon @Barza
		- Now a charged attack
		- Damage boosted to 1-2 hearts
	- Microblock crafting was completely reworked @Barza and Micomi
		- The crafting mechanic itself was redone from scratch
			- The new one is less sensitive to crafting grid positioning, and comes with 100% less dupe bugs (Hopefully)
		- Comes with an EMI integration for the different microblock cutting and combining recipes
		- A lot more materials are now available for microblock crafting
			- And by a lot more, we mean nearly **1800** different blocks!.
			- The materials are from: Abyssal Decor, AE2, Architect's Palette, Atmospheric, Botania, Create, Create Deco, Decorative Blocks, Echovoids, Fang's Textiles and Trinkets, Hearth and Home, Immersive Engineering, Immersive PEtroleum, Industrial Hellscape, Nature's Spirit, Biomes We'Ve Gone, Quark, Tasty Tiles, 
		- To avoid longer load times, the EMI index now lists only one set of microblocks.
		- A new EMI tab listing all the microblock materials, along with the set of microblock they can make is now available.
	- A significant amount of Botania gadgetry was shifted to be still Tier 1 but before 1080 steel. @Barza
		- The mana prism does not take annealed glass anymore. This makes mana tablets and mana blasters available pre-1080.
		- Mana tablets being available enables using a lot of Botania's rods, which were craftable pre-1089, just not usable.
		- They also enable crafting rings of mana pre-1080, unlocking a whole loop of Botania curios, each obtained by transforming the previous one with an alchemy catalyst.
